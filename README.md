# Applied Data Analysis Coursework

A selection of projects from a semester-long applied data analysis course, where I completed a new weekly project (13 total) covering a widening set of tools and harder questions each week, starting with core Pandas and moving into visualization, datetime handling, and geospatial work. These three are the ones I'd actually put in front of someone, picked for the strongest analysis and the widest range of tools.

## Projects

**[Death Records: Demographics, Marital Status, and Age Patterns](death-records-demographics/)**
Cleaning and decoding a large U.S. death records dataset, then using bar and box plots to look at how age at death varies by marital status and how that mix shifts at 60, 70, and 80 years old.
*Pandas, matplotlib, seaborn*

**[Zillow Housing Market Analysis by Region](zillow-housing-market/)**
Grouping state-level Zillow housing data into U.S. regions to compare listing prices, days on market, and inventory, and to see whether a clearer supply-and-demand story emerges at the regional level than the state level.
*Pandas, numpy, matplotlib, seaborn*

**[Geospatial Visualization: State Parks, F1 Circuits, and US Housing Inventory](geospatial-mapping/)**
Building interactive maps with folium, from Indiana state park markers and a connecting route, to global F1 circuit locations, to a choropleth of U.S. housing inventory built by merging Zillow data with state boundary shapefiles.
*Pandas, geopandas, folium, branca*

## A note on where this came from

These started as weekly assignments in an applied data analysis course. For each one, I removed the original assignment structure (question numbering, submission pledge, TA-help disclosure) and relabeled the sections to reflect what the analysis actually covers, but the code and analysis are my own original work from the course. The other 10 weekly projects covered more introductory Pandas fundamentals and aren't included here since these three better represent the range of tools and depth of analysis from the course.
